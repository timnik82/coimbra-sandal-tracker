# Sandal Tracker

Интерактивный журнал поиска мужских закрытых сандалий с полноценной амортизацией, размерами EU 46–47 и ориентиром по цене до €100.

## Возможности

- компактные раскрывающиеся карточки моделей;
- фильтры по пригодности и статусу просмотра;
- отметки «интересно», «хочу примерить» и «к покупке»;
- личные заметки, сохраняемые только в браузере;
- отдельный архив исключённых моделей с объяснением причин;
- ссылки на найденные страницы магазинов и производителей.

## Локальный запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
```

Цены и наличие в карточках отражают результаты конкретной поисковой сессии и могут измениться.
