# Sandal Tracker

Интерактивный журнал поиска мужских закрытых сандалий с полноценной амортизацией, размерами EU 46–47 и ориентиром по цене до €100.

## Возможности

- компактные раскрывающиеся карточки моделей;
- фильтры по пригодности и статусу просмотра, а также сортировка по актуальности,
  цене, амортизации и доступности;
- структурированные отметки цены, размеров 46/47, доставки в Португалию,
  примерки в Коимбре, офисного вида и даты проверки;
- выбор от двух до четырёх моделей и сравнительная таблица;
- отметки «интересно», «хочу примерить» и «к покупке»;
- личные заметки с удалённой синхронизацией и резервным сохранением в браузере;
- отдельный архив исключённых моделей с объяснением причин;
- пользовательский архив просмотренных моделей с возможностью восстановления;
- синхронизация заметок, фаворитов, статусов и фильтров между устройствами;
- компактный индикатор личного аккаунта и состояния синхронизации;
- журнал выполненных поисков с источниками, запросами и причинами отсева;
- ссылки на найденные страницы магазинов и производителей.

Полный каталог уже найденных моделей хранится в `public/tracker.html` в массиве
`products`. Перед новым поиском агенту следует сверяться с этим каталогом и с
разделом «Архивировано», чтобы не добавлять повторно уже рассмотренные модели.
Отклонённые и недостаточно подтверждённые модели остаются в каталоге и при
первом открытии автоматически помещаются в пользовательский архив.

Каждая модель содержит структурированные поля `lastChecked`, `priceEur`,
`retailer`, `size46`, `size47`, `portugalDelivery`, `coimbraTryOn`,
`officeSuitability` и `evidenceUrl`. Если источник не подтверждает значение,
оно должно оставаться `null` или `unknown` — свободный текст и маркетинговые
формулировки не считаются доказательством.

Допустимые статусы размеров: `in_stock`, `size_exists`, `out_of_stock`,
`unknown`; доставки: `confirmed`, `unavailable`, `unknown`; примерки:
`confirmed`, `possible`, `unavailable`, `unknown`; офисного вида: `good`,
`acceptable`, `sporty`, `unknown`. Выбранная сортировка и до четырёх моделей
для сравнения входят в пользовательские настройки и синхронизируются через
`/api/state` без отдельной миграции базы.

## Локальный запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
```

Цены и наличие в карточках отражают результаты конкретной поисковой сессии и могут измениться.
